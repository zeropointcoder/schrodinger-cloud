# State Tomography Reconstruction

Constructs and analyse a multi-qubit entangled circuit by validating measurement correlations from simulation results.


## Overview
- Builds a deterministic `multi`-qubit circuit with superposition and chained entanglement

- Executes the circuit on simulator with repeated measurements

- Aggregates bitstring outcomes into a probability distribution

- Computes correlation statistics to validate entanglement behaviour


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 state_tomography_reconstruction.py
```

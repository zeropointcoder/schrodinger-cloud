# Quantum Logic Circuits

Simulates and analyses a small 3-qubit quantum circuit with entanglement insights.


## Overview
- Builds a `3`-qubit quantum circuit with configurable gates.
- Measures qubits and collects statistics.
- Analyses correlations between qubits to highlight `entanglement`.
- Plots a histogram of measurement outcomes.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 quantum_logic_circuits.py
```

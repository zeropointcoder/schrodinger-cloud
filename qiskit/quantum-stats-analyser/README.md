# Quantum Stats Analyser

To simulate quantum circuits and analyse the resulting measurement statistics.


## Overview
- Create circuit: Make `2` qubits, apply `Hadamard` and `CNOT`, then measure.

- Simulate: Run the circuit on simulator `multiple` times.

- Analyse: Convert counts to probabilities.

- Visualise: Print results and show a histogram.


## Requirements
```bash
pip3 install -r requirements.txt
```

## Run
```bash
python3 quantum_stats_analyser.py
```

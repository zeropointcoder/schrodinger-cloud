# Qubit rotator

To Visualise Qubit Rotations on the `Bloch Sphere`.


## Steps
- Initialise a `single`-qubit circuit.

- Apply random rotations around `X`, `Y`, `Z` axes.

- Simulate the circuit to obtain the `statevector`.

- Visualise the qubit on the `Bloch` sphere.

- Measure the qubit and plot the `probability` histogram.


## Requirements
```bash
pip3 install -r requirements.txt
```

## Run
```bash
python3 qubit_rotator.py
```

# Quantum Circuit Tool

Build and visualise multi-qubit quantum circuits, including Bell and GHZ states.


## Overview
- Initialises a quantum circuit with a specified number of qubits.

- Allows adding `Hadamard` and `CNOT` gates dynamically.

- Supports generating `Bell` and `GHZ` states automatically.

- Measures all qubits and simulates the circuit.

- Returns measurement counts and plots histogram of outcomes.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 quantum_circuit_tool.py
```

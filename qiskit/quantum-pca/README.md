# Quantum PCA

A quantum-inspired analysis of multi-qubit variance patterns using entangled rotations and measurement statistics.


## Overview
- Encode classical `data` into qubit rotations.

- Introduce entanglement to capture correlations between qubits.

- Measure all qubits to obtain probability distributions of outcomes.

- Compute a `variance-like` signature from measurement probabilities to quantify spread and correlations.

- Visualise the results with a histogram.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 quantum_pca.py
```

# Four-qubit Entanglement

Demonstrates 4-qubit entanglement and visualises measurement outcomes.


## Overview
- Initialise a `4`-qubit quantum circuit with classical registers.

- Apply a chain of `Hadamard` and `CNOT` gates to entangle all qubits.

- Measure all qubits.

- Display counts in a histogram.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 four_qubit_entanglement.py
```

# Bell Inequality Test

Implement simulation demonstrating violation of the `CHSH` Bell inequality using entangled qubits.

## Overview
- Prepare a maximally entangled `Bell state`
- Apply different measurement bases using `Y-rotations`
- Measure qubit correlations for `four angle` combinations
- Compute expectation values from parity of outcomes
- Combine results into the `CHSH` expression
- Observe violation `(|S| > 2)` predicted by quantum mechanics

## Requirements

```bash
pip3 install -r requirements.txt
```

```bash
python3 bell_inequality.py
```

# Quantum Chemistry Lab

Implement quantum chemistry–inspired circuits for `H₂` and `LiH`. 

The `“H₂”` here means - `“A minimal circuit inspired by the correlation structure of H₂”`


## Overview
- Define a `molecule`-inspired parameterised quantum circuit.

- Bind parameters and run the circuit on a simulator.

- Measure qubits and visualise probability distribution.

- Easily extendable to different small molecules.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 quantum_chemistry.py
```

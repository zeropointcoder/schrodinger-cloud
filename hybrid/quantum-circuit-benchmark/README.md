# Quantum Circuit Benchmark

Benchmarking entanglement generation and measurement fidelity across Qiskit and Cirq for small-scale quantum circuits.


## Overview
- Constructs a `Bell` state circuit in both Qiskit and Cirq.
- Runs circuits on simulators with `multiple` shots.
- Compares measurement statistics between `frameworks`.
- Plots histograms to visualise measurement outcomes.


## Requirements
```bash
pip install -r requirements.txt
```

## Run
```bash
python3 quantum_circuit_benchmark.py
```
